# Shirdi Sai Baba wallpaper

`shirdi-sai-baba-original.jpg` is the 3,680 × 4,868 archival portrait
“Sai baba rare original PRINT.jpg” by Debashish Genaamd, downloaded from
Wikimedia Commons.

- Source: https://commons.wikimedia.org/wiki/File:Sai_baba_rare_original_PRINT.jpg
- License: CC BY-SA 4.0
- Modification: the 4K wallpaper uses the same portrait over a darkened,
  blurred copy of the photograph so the complete portrait fits a landscape
  desktop without cropping.

The derived `shirdi-sai-baba-wallpaper-4k.jpg` is distributed under the same
CC BY-SA 4.0 license.
